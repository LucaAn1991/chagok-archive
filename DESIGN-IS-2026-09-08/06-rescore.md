## 점수

**1. innovative — 2/3** (변화 없음)
   상황 사다리(`page.tsx:377-386`)는 그대로다. 이번 작업은 전부 **덜어내기**였고 새 형태를 더하지 않았다.
   Justification: 기존 형태의 분명한 개선 — 앵커 2.

**2. useful — 2 → 3/3** ▲
   Evidence: A 분기가 「Featured 1장 + 곁들임 4장」이 되면서 **primary CTA 1개**(실측). 헤드라인이 개수를 말하고, 다음 행동이 화면에서 하나로 정해진다. 상한을 넘긴 카드는 아래 목록이 받는다(실측 8개).
   Justification: 주 과업이 **최소 단계**로 끝나고 미끼 동작이 없다 — 앵커 3. 아래 목록은 미끼가 아니라 이번 주 일정이라는 별개의 정보다.

**3. aesthetic — 2 → 3/3** ▲
   Evidence: 렌더된 색 9개·타이포 10종·radius 4종·그림자 1종이 **전부 토큰**, 고아 스타일 0건(실측). 강조색은 primary CTA·활성 상태·상태 점·이미지 자리에만 나타나고 면적 9.6%. 「로딩」 표현이 하나로 통일됐다.
   Justification: 하나의 보이는 체계를 따르고 고아 스타일이 없다 — 앵커 3. 최초 감사에서 깎았던 두 가지(면적 28.3% · 로딩 2종)가 모두 사라졌다.

**4. understandable — 2/3** (변화 없음)
   Evidence: 「전체보기」 → 「캘린더에서 보기」로 목적지를 적었고(`page.tsx`), CTA가 상태를 따라간다 — 「업로드 대기」 카드에 **「이어서 보기」**가 나오는 것을 실측했다.
   Justification: 주 조작은 전부 이름이 맞다. 다만 **「제작 대기 / 업로드 대기」가 여전히 형태가 비슷하다** — 09-01 팀 합의라 손대지 않았다. 그 한 가지가 남아 3이 아니다.

**5. unobtrusive — 2 → 3/3** ▲
   Evidence: 상단 바는 흰 바탕·1px 선이고 활성 표시만 연한 강조면이다. 홈은 뒤로가기·화면 제목이 없고 인사는 캡션 줄이다. 곁들임 카드가 7장 268px에서 **4장 156~196px**로 줄어 첫 장이 화면을 이끈다.
   Justification: 크롬이 물러나고 내용이 그림, UI가 바탕이다 — 앵커 3. (동일한 자리표시 4개가 여전히 큰 면을 차지하는 문제는 #10에서 센다.)

**6. honest — 3/3** (유지)
   Evidence: 과장·다크 패턴 0건. 자동 이월 고지, 경고색 없는 에러, 가짜 진행률 금지 그대로. 여기에 **CTA가 카드 상태와 1:1로 맞게** 됐다(`cardCtaLabel()` 한 곳).
   Justification: 모든 문구·배지·라벨이 실제 동작과 맞는다 — 앵커 3. 최초 감사에서 「일관성 문제로 옮겨 셌다」고 유보한 항목이 실제로 해소됐다.

**7. long-lasting — 2 → 1/3** ▼
   Evidence: 유행 표식이 **2개**다 — ① 「AI = ✦(Sparkles)」 관용(`AppTopNav.tsx`, 자리표시) ② **산성 라임(`--action: #D5F267`)**. 라임/샤르트뢰즈는 2023~2025년 SaaS·AI 브랜딩에서 가장 많이 쓰인 강조색 계열이다.
   Justification: 유행 표식 2~3개 — 앵커 1. **이 항목만 이번에 내려갔고, 원인은 팔레트 교체다.**
   ⚠️ 열 개 중 확신이 가장 낮은 판정이다. 「지금 시대를 읽는 색」인지 「지금 유행하는 색」인지는 갈리고, 브랜드 변별력을 이 1점보다 높게 볼 수 있다. 감사는 앵커대로 적을 뿐 결정은 사람 몫이다.

**8. thorough — 1 → 3/3** ▲▲
   Evidence: 상태 6종이 모두 처리됐다 — empty(D 분기) · loading(**골격 1종으로 통일**) · error(인라인+재시도) · success(이월 한 줄 `role=status`) · focus(전역 2px) · **disabled**(§13 신설 — 「비활성화하지 않고 문구로 교체」를 규칙으로 확정, 코드가 이미 그렇게 동작).
   디테일: 44px 위반 **0/22**, `prefers-reduced-motion`이 `animate-pulse`까지 덮음(CSSOM 확인), 반쪽 ARIA 탭 제거(`role=tab` 0 · `aria-pressed` 2), skip link 도입, 제목 단계 정상.
   Justification: 여섯 상태가 모두 있고 «고려됐다» — 앵커 3.

**9. environmentally friendly — 1 → 2/3** ▲
   Evidence: 폰트가 평소 **424 KB**(unicode-range 2분할, 커버리지 손실 0). 유휴 애니메이션 0 · 초기 팝업 0 · 서드파티 0 · reduced-motion 완전 적용.
   Justification: 확정 페이로드가 500 KB 아래로 내려왔고 모션이 통제된다 — 앵커 2. **다크 모드 미지원**(의도된 결정)이라 3은 아니다.

**10. as little design as possible — 1 → 2/3** ▲
   Evidence: 지운 것 — 출력 0이던 `PageHeader`, 배지와 중복되던 자리표시 문구, 참조 0건 `audienceDateLine`·`formatMonthDay`, `GREETING_SLOTS` export, 동등 CTA 6개.
   남은 제거 후보 **2개** — ① 인사 헤더 + `greetings.ts` 9구간 표 ② 데스크톱에서 로고와 홈 탭이 둘 다 현재 화면을 가리킴.
   Justification: 제거 가능 요소 2개 이하 — 앵커 2.
